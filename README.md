## 🎬 About The Project

<img align="right" width="380" src="https://user-images.githubusercontent.com/74038190/216122041-518ac897-8d92-4c6b-9b3f-ca01dcaf38ee.gif">

**NestTube** is a modern, YouTube-inspired video streaming platform crafted with a sleek, responsive interface and an exceptional user experience.

Built on a fast **React 19 + Vite 6 + TypeScript** stack and styled with **Tailwind CSS v4**, NestTube brings together trending video discovery, powerful search, personalized recommendations, playlists, subscriptions, and buttery-smooth playback — all wrapped in a fluid, animation-rich UI powered by **Motion (Framer Motion)**.

> ✨ Designed & Developed with passion by **[Naim Xbz](https://github.com/naimxbzbd)**

## 🏁 Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites

Make sure you have the following installed:

```bash
node -v   # v18 or higher recommended
bun -v    # Bun package manager (or use npm/yarn/pnpm)
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/naimxbzbd/NESTTUBE.git

# 2. Move into the project directory
cd NESTTUBE

# 3. Install dependencies
bun install
# or: npm install / yarn install / pnpm install
```

### Environment Variables

Duplicate the example env file and fill in your own keys:

```bash
cp .env.example .env
```

| Variable         | Description                                  |
|------------------|-----------------------------------------------|
| `GEMINI_API_KEY` | API key for Google GenAI-powered features     |

### Running the App

```bash
# Start the development server
bun run dev

# Build for production
bun run build

# Preview the production build
bun run preview
```

The app will be available at **`http://localhost:3000`** by default.

## 📁 Project Structure

```bash
NESTTUBE/
├── assets/               # Static assets & AI studio files
├── src/                  # Application source code
│   ├── components/       # Reusable UI components
│   ├── pages/             # Route-level views
│   ├── store/             # Zustand state stores
│   ├── hooks/             # Custom React hooks
│   └── main.tsx           # App entry point
├── .env.example          # Sample environment variables
├── index.html            # HTML entry point
├── metadata.json         # Project metadata
├── package.json          # Dependencies & scripts
├── tsconfig.json         # TypeScript configuration
└── vite.config.ts        # Vite configuration
```
